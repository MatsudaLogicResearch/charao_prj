# charao テスト計画

## テスト方針

| フェーズ | 条件 | 内容 |
|---------|------|------|
| **フェーズ1（現在）** | ngspice不要 | 計算・変換関数のユニットテスト |
| **フェーズ2（次）** | lrPymRPC経由でngspice実行可能 | OSU035サンプルで1回実行し基準ファイルを作成 |
| **フェーズ3** | 基準ファイルあり | コード変更後に再実行して回帰テスト |

---

## テスト実行環境

### フェーズ1（ユニットテスト）
| 項目 | 内容 |
|------|------|
| **OS** | Windows 11 |
| **Python** | 3.10以上 |
| **テストFW** | pytest |
| **仮想環境** | `$HOME/.venv_charao` |
| **インストール** | `pip install -e ".[dev]"` |
| **実行コマンド** | `pytest -v` |

### フェーズ2・3（E2Eテスト）
| 項目 | 内容 |
|------|------|
| **実行方式** | lrPymRPC（gRPC）経由でリモートLinuxサーバー上でcharaoを実行 |
| **ngspice** | リモートLinuxサーバー上で実行（Windowsへの導入不要） |
| **基準ファイル** | `tests/fixtures/` に保存 |
| **検証内容** | 出力`.lib`/`.v`を基準ファイルと差分チェック |
